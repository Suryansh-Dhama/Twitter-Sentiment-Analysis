# Twitter Sentiment Analysis

This project performs sentiment analysis on tweets to classify them as Positive, Negative, or Neutral using Natural Language Processing (NLP) and Machine Learning techniques.

## Objective

To build a machine learning model that can analyze the emotional tone behind tweets using cleaned and preprocessed text data.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas, NumPy
- Scikit-learn
- NLTK
- Matplotlib, Seaborn

## Dataset

The dataset used contains tweets and their sentiment labels.  
Source: [Kaggle Twitter Sentiment Dataset](https://www.kaggle.com/datasets) (replace with actual link if possible)

## Features

- Data cleaning (removing punctuation, stopwords, links)
- Text preprocessing and tokenization
- TF-IDF vectorization
- Model training using Logistic Regression / Naive Bayes
- Accuracy and performance metrics
- Visual representation of results

## How to Run

1. Clone the repository
2. Install required libraries using:
    bash
    pip install -r requirements.txt
    
3. Open Twitter_Sentiment_Analysis.ipynb in Jupyter Notebook
4. Run all cells to train and evaluate the model
